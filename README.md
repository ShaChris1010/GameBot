## 安裝
1. 下載上面的 zip，**整包解壓**到任一資料夾（例如桌面）
2. 雙擊 `GameBot.exe`
3. 詳細操作看包內的 **使用說明.txt**
4. 若 Windows 跳「已保護您的電腦」→ 點「其他資訊」→「仍要執行」

## 更新
程式開機會自動檢查版本。跳出「必須更新」視窗時：
回到本頁下載最新 zip → **整包解壓覆蓋舊資料夾**（不能只換 exe）→ 重新開啟。
